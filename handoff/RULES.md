# Shared rules (all apps)

- **Build only when the user says "build".** Show samples / screenshots before design changes.
- "Just note (down)" = add to `inkwell/ROADMAP.md` (or the app's handoff file) only — no code.
- Speed and crispness come first. Calm, light, classy design (warm cream, sage, gold) — not dark/gloomy.
- Private repo `drdilips1/bytewatch-stremio-addon`, branch `claude/books-tbm-apk-enhancement-h1p51j`:
  commits carry `[skip ci]` (except a deliberate build-trigger commit), fetch + rebase before pushing.
  Commit trailers: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` and
  `Claude-Session: <session link>`.
- Never commit keystores/secrets; never ask for or share passwords/tokens. No model ids in commits or
  code comments.
- **Public AudioYam must never contain** MAM / MyAnonamouse, Mobilism, Libby, Anna's Archive,
  Bookshare, tracker code, own encrypted sync. Grep before pushing to it.
- GitHub comments end with the "Generated by Claude Code" footer.
- Each app lives in its own folder; a window changes only its app's folder (shared `inkwell/src/` code
  is shared by Audiohub+, Hearth, Duet and Audibrisk — say so before changing it).
- After a build: report the version and link; if an iPhone build queues for lack of a Mac runner
  (private repo minutes), say so and don't re-run.
